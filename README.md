# Bank Management System | C++

Developed a menu-driven Bank Management System using C++ and Object-Oriented Programming (OOP) concepts.

Implemented core banking operations, including account creation, deposits, withdrawals, and balance inquiry.

Used classes, objects, member functions, and encapsulation to organize account information and banking operations.

Implemented input validation and balance checks to prevent invalid transactions and insufficient-balance withdrawals.

Designed an interactive console-based interface for easy navigation and account management.
